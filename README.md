# Abiamamela Obi-Obuoha Portfolio

A responsive, accessible portfolio for Abiamamela Obi-Obuoha, presenting work across robotics, artificial intelligence, data science and intelligent physical systems.

## Local preview

Run a static server from this directory:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Adding a new project

Copy an existing `project-card` block in `index.html`, update the project copy and links, then add any project image to `assets/`. Keep claims measurable and link to public evidence when available.

## GitHub Pages

Publish this repository from the `main` branch and repository root in **Settings → Pages**.
